# NexusSklad Tech Decisions

Дата: 1 марта 2026
Статус: начальные решения

## Выбранный стек

### Mobile

- `Flutter`

Причина:

- быстрый запуск;
- сильная мобильная часть;
- хорош для owner/staff workflows.

### Web

- `React + TypeScript + Vite`

Причина:

- быстрый web/admin старт;
- гибкость;
- хорошая экосистема.

### API

- `Node.js + TypeScript + Fastify`

Причина:

- быстрый backend MVP;
- типизация;
- удобный REST API слой.

### ORM

- `Prisma`

Причина:

- миграции;
- типы;
- быстрый старт.

### Database

- `PostgreSQL`

Причина:

- надежность;
- хороший fit для складских сущностей и отчетов.

## Пока не берем

- Redis;
- event bus;
- микросервисы;
- Kubernetes;
- сложные DDD-слои;
- GraphQL.

## Причина

Нужно сначала доказать ценность продукта, а не строить избыточную инфраструктуру.
