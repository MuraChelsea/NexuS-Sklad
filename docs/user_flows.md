# NexusSklad User Flows

Дата: 1 марта 2026
Статус: draft

## 1. Цель

Описать основные пользовательские сценарии нового складского продукта.

## 2. Flow: Регистрация компании

### Участник

- владелец

### Шаги

1. Открывает приложение.
2. Нажимает `Создать компанию`.
3. Вводит название компании.
4. Вводит имя, телефон/email, пароль.
5. Подтверждает регистрацию.
6. Попадает в пустой workspace.

### Результат

- создана компания;
- пользователь получает роль `owner`.

## 3. Flow: Добавление первой категории и товара

### Участник

- owner / manager

### Шаги

1. Открывает раздел `Товары`.
2. Создает категорию.
3. Нажимает `Добавить товар`.
4. Заполняет карточку товара.
5. Сохраняет товар.

### Результат

- товар появляется в каталоге;
- остаток изначально равен 0 или задан стартовым значением.

## 4. Flow: Приход товара

### Участник

- owner / manager / staff

### Шаги

1. Открывает `Операции` или карточку товара.
2. Выбирает `Приход`.
3. Выбирает товар.
4. Указывает количество.
5. Добавляет комментарий/поставщика по желанию.
6. Сохраняет операцию.

### Результат

- создается запись движения;
- остаток увеличивается;
- операция видна в истории.

## 5. Flow: Расход товара

### Участник

- owner / manager / staff

### Шаги

1. Открывает `Операции` или карточку товара.
2. Выбирает `Расход`.
3. Выбирает товар.
4. Указывает количество.
5. Добавляет комментарий.
6. Сохраняет операцию.

### Результат

- создается запись движения;
- остаток уменьшается;
- операция видна в истории.

## 6. Flow: Поиск товара

### Участник

- owner / manager / staff

### Шаги

1. Открывает раздел `Товары`.
2. Использует поиск по названию или SKU.
3. Открывает найденный товар.

### Результат

- пользователь быстро получает доступ к нужной позиции.

## 7. Flow: Просмотр истории движений

### Участник

- owner / manager

### Шаги

1. Открывает `История движений`.
2. Фильтрует по дате/товару/сотруднику.
3. Просматривает нужные операции.

### Результат

- появляется прозрачность по движению товара.

## 8. Flow: Инвентаризация

### Участник

- owner / manager / staff

### Шаги

1. Owner или manager запускает инвентаризацию.
2. Сотрудник идет по списку товаров.
3. Вводит фактические остатки.
4. Система считает расхождения.
5. Owner/manager завершает инвентаризацию.

### Результат

- создается отчет по расхождениям;
- фиксируется результат инвентаризации.

## 9. Flow: Управление ролями

### Участник

- owner

### Шаги

1. Открывает `Пользователи`.
2. Добавляет сотрудника.
3. Назначает роль.
4. При необходимости деактивирует доступ.

### Результат

- у сотрудника появляются разрешенные сценарии работы.

## 10. Flow: Ежедневный контроль владельца

### Участник

- owner

### Шаги

1. Открывает главный экран или отчет.
2. Видит остатки, приходы, расходы, предупреждения.
3. При необходимости открывает движения.

### Результат

- владелец быстро понимает текущее состояние склада.
